# Security Policy — CHEATZ ANIME

---

## Authentication & Session Management

- Laravel Sanctum bearer tokens for API authentication
- Tokens revoked on logout
- Suspended/banned accounts rejected at middleware level
- Password reset tokens are single-use and expire
- Password change revokes all other active tokens

## Authorization

- **Role-based:** super_admin, content_manager, subtitle_editor, support_agent, user
- **Policy-based:** AnimePolicy enforces per-resource authorization
- **Gate::before:** Super admins bypass gates; all other roles must have explicit permissions
- Permissions enforced on the backend — frontend UI hiding is cosmetic only
- Regular users cannot access admin routes (role middleware)
- Users cannot modify another user's profile, history, or subscription
- Super admin role cannot be assigned by non-super-admins
- Super admin cannot be suspended by content managers

## Mass Assignment Protection

All models use `$fillable`. Sensitive fields excluded:
- `video_source_url` — set only via `setVideoSourceUrl()` method
- `status` on User — only settable by admins via dedicated endpoints
- Role fields — only assignable via Spatie HasRoles methods

## API Response Safety

These fields are **never** included in API responses:
- `video_source_url` — internal reference, served only via signed PlaybackController URL
- `subtitle_track.file_path` — internal path, served only via HMAC-signed stream endpoint
- `payment_transaction.provider_signature` — stored for audit, never re-exposed
- `payment_transaction.provider_response` — raw webhook payload, not in public responses
- User `password`, `remember_token`

## Payment Security

- Subscription is activated **ONLY** via verified Razorpay webhook
- Webhook signature verified with HMAC-SHA256 using `RAZORPAY_WEBHOOK_SECRET`
- Idempotency via `webhook_event_id` unique index — duplicate events silently skipped
- All subscription state changes wrapped in DB transactions
- `RAZORPAY_KEY_SECRET` and `RAZORPAY_WEBHOOK_SECRET` are server-only environment variables
- `RAZORPAY_KEY_ID` (public) is the only payment credential exposed to the browser

## Subtitle Security

- Files stored in private Laravel `local` disk (not `public`)
- Never stored in `storage/app/public/`
- Served only via `SubtitleController::stream()` with HMAC token validation
- Token includes: subtitle_id, user_id, expiry (4h)
- Path traversal prevented — paths generated by the server, never from user input
- SHA-256 checksum stored for integrity verification

## Content Licensing

- `content_licenses` table tracks provider, territory, start/end dates
- `Anime::isLicensed()` check gates playback authorization
- Playback denied if no active valid license exists
- Content provider credentials stored server-side only, never in browser

## Rate Limiting

| Endpoint | Limit |
|----------|-------|
| POST /auth/register | 10/min |
| POST /auth/login | 10/min |
| POST /auth/forgot-password | 5/min |
| POST /auth/reset-password | 5/min |
| POST /webhooks/razorpay | 100/min |
| General API | 60/min |

## Input Validation

All inputs validated via Laravel Form Requests before controller logic runs.  
Validation errors return 422 with structured field-level messages.

## Error Handling

- Production: generic error messages only (no stack traces, no debug info)
- `APP_DEBUG=false` in production is mandatory
- Structured JSON error responses — no HTML error pages from API routes

## Storage

- Subtitle files: `storage/app/subtitles/YYYY/MM/{random40chars}.{ext}`
- User avatars: `storage/app/public/avatars/` (public disk, safe paths)
- No user-controlled file names stored or used in filesystem paths

## Security Headers (Next.js)

Set for all routes:
- `X-Content-Type-Options: nosniff`
- `X-Frame-Options: DENY`
- `X-XSS-Protection: 1; mode=block`
- `Referrer-Policy: strict-origin-when-cross-origin`

## Secrets Management

- Never commit `.env` files (excluded in `.gitignore`)
- Use `.env.example` with placeholder values
- Rotate `APP_KEY` if compromised
- Rotate Razorpay webhook secret if compromised (update in provider dashboard + .env)
- Use a secrets manager (AWS Secrets Manager, Vault) in production

## Dependency Security

- Run `composer audit` and `npm audit` before deployment
- Pin dependency versions in `composer.json` and `package.json`

## Reporting Vulnerabilities

Email: security@cheatz.anime  
Do not disclose security issues publicly until patched.
